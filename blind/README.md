# Module Shop Blind Vault · 遗迹盲仓暗标竞拍

模块商店的附属模组：在商店左侧功能区增加「暗拍」页面（AtomLib 不可用时用原版回退界面，也可用快捷键打开）。

| 项 | 值 |
| --- | --- |
| modid | `module_shop_blind` |
| 版本 | 3.4.0（网络协议 "7"） |
| 前置 | 模块商店 1.0.3+（两端）· AtomLib 0.1.0-beta 起（仅客户端，已验证 0.4.0） |
| 许可 | MIT |

## 玩法

1. **备战 → 匹配 → 竞拍 → 开仓**：服务端多房间并行，人数不足由 AI 补位（AI 只按公开信息出价）。
2. 8×6 仓库，藏品占 1–4 格、6 种品质；系统每轮公开揭示部分藏品，估值按已揭示格子推算。
3. 7 种鉴定师角色按轮次生效，5 种道具（每种每局 1 次、每轮 1 个）。
4. 报价提交即锁定、超时按 0；上一轮报价全员公开；前 4 轮有秒仓倍率（2.0 / 1.6 / 1.4 / 1.2），第 5 轮价高者得。
5. 中标按净额一次结算，付不起即流拍；真人中标亏损时按比例分红给同局真人。
6. 三档门票 1 万 / 50 万 / 150 万（需持有门票 3 倍以上余额），稀有及以上藏品有残损 / 完美成色；门票记在存档的 `feeLedger`，关服或异常退出后开服退回；全服最近 10 笔成交可查。

资金全部经模块商店公共 `EconomyApi` 结算。

## 构建

```bash
./gradlew build -Pmodule_shop_root=<模块商店主仓库目录>   # 产物：build/libs/module_shop_blind-3.4.0.jar
```
