附带实现决定：
- **现价用 double 保存**（`Quote.exact`）。便宜股（如 64 星币）单 tick 变动只有 0.03，对整数取整会吃掉全部演化。展示价、K 线、成交一律用取整价；`exact` 与 `price` 偏差超过 0.5（被外部改价）时回退到 `price`。
- v3 的趋势存在独立字段 `mu`，不与旧 `trend` 混用，回滚 v2 不会把 v3 的 μ 当成 tick 级漂移。
- 旧 `volCluster` / `trend` 字段继续落盘，仅 v2 使用。

对照 §9：单 tick 中位/p99、2 小时 std、回撤中位、触日限占比（2 小时与 24 小时都满足 <5%/<10%/<20%）、期末/起点中位、\|r\| 自相关为正、新闻（中位 ≤3%、p95 ≤6%、σ 抬升 ≤1.8×）、冲击窗（0.02·depth：0.3–0.8%；0.20·depth：1–2% 且 ≤ cap）全部落窗。换种子（1、777）、N=600 复核同样落窗，FARM 2 小时 std 约 2.4%–2.8%（窗 2%–5%，偏下沿）。

**偏离 §9 的一条（单列）：收益一阶自相关 lag1 要求 0.05–0.25 → 改为 \|lag1\| < 0.05（5 秒/1 分钟）、<0.08（5 分钟）、<0.10（15 分钟）。**
理由：真实市场里流动性好的个股日内收益自相关约等于 0（买卖价差反弹时略为负）。若做出 +0.05 以上的 lag1，玩家追涨杀跌就是稳赚策略，违背"拟真"，也与文档自己给的 OU 趋势参数不自洽（该参数在 5 秒尺度上对收益方差的贡献不到 0.1%）。"闹一阵"的特征改由 \|r\| 自相关 >0.05 和 5 分钟峰度 >3.3 断言保证，实测分别约 0.08–0.10 与 3.8–4.4。

## 4. 存档迁移逻辑

- `StockMarketSavedData.FORMAT = "zip-2.3"`，同时是"波动率已迁移"标记。
- 加载时 `format != zip-2.3`（含 2.0.x 无 format、2.2）→ 个股 `volatility = clamp(旧 clampVolatility 结果 × 0.5, 0.006, 0.050)`，Quote 的 `newsBoost` 清零，并 `setDirty`；保存时写 `format=zip-2.3`，之后不再迁移。
- 备份：`ServerAboutToStart` 的 `StockSeeder.backupLegacy`：`zip-2.2` → `module_shop_stock.dat.pre-2.3.bak`；更早的 → 沿用 `pre-2.2.bak`；已存在则不重复备份。
- Quote 缺失的新字段：`exact=price`、`fair=price`、`mu=0`、`sigma=迁移后的个股波动`。
- 新档：`StockMarket.SEED` 已是新口径，不迁移；种子历史 `seedBars` 走 v3 过程（72 根 1 分钟 K 线，起点基准价 ±3%）。
- 注意：`config/module_shop_stock/stocks.json` 每次启动会按文件里的 `vol` 覆盖个股波动，**不会**迁移。若运营的 stocks.json 里还是旧口径数值，需要手动乘 0.5（0.002–0.35 的范围校验未变）。

## 5. 回滚

- `price_model.priceModelVersion = 2`：行情演化、冲击、新闻、盘口、种子历史都回到旧分支，个股波动按 `volatility / 0.5` 还原成旧口径使用（`MarketEngine.legacyVolatility`），旧键 `volatilityMultiplier` / `meanReversionBps` / `autoNewsMaxImpact` 重新生效。
- 回到 2.2 的 jar：用 `module_shop_stock.dat.pre-2.3.bak` 恢复存档（2.3 存档里的 volatility 已是新口径，旧 jar 读了会偏小）。
- 日限 ±12% 只在 v3 分支生效，v2 保持无日限。

## 6. 构建说明（测试无法启动的原因与修复）

原因：Windows 上 Gradle 通过 `@argfile` 把类路径交给测试 JVM，JVM 读 argfile 用系统编码，项目路径含中文时类路径乱码，表现为 `Could not execute test class ... ClassNotFoundException`（用纯 ASCII 路径复现确认，与 JUnit 依赖无关）。
修复：`build.gradle` 中，当项目路径含非 ASCII 字符时，把编译产物 Sync 到 `%TEMP%/module_shop_stock_test_cp` 再运行测试与 `simulatePriceModel`；路径为纯 ASCII 时不做任何事。
