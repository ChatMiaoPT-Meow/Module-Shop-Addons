## 0. 一句话结论

把「每 5 秒一次的高倍高斯乱跳 + 硬切趋势 + 大跳空新闻」换成：

**对数价格上的均值回归漂移 + 按真实时间缩放的波动率 + EWMA 随机波动率 + 温和新闻冲击 + 日振幅护栏 + 平方根成交冲击**。

白话：价格大多时候像真实股市那样「慢慢晃」，偶尔热闹一下；玩家大单会推价，但不会无分钟过山车把服务器经济打穿。

## 1. 现状核实（对照源码）

### 1.1 时钟与会话

| 项 | 现状 | 源码位置 |
| --- | --- | --- |
| 行情 tick | 默认每 **5 秒** 一次 | `UPDATE_INTERVAL_SECONDS=5` |
| 会话 | `SESSION_ALWAYS_OPEN=true`，几乎永远开市 | `MarketEngine.sessionOpen` |
| 日切 | 按 `LocalDate` 写 `prevClose`，重置日高/低/量 | `rollDayIfNeeded` |
| 停牌 | `def.halted` 时只采样、不演化 | `tick` 循环 |

### 1.2 `evolveAndSample` 当前公式（每 tick）

```
baseSigma = max(0.004, def.volatility * VOLATILITY_MULTIPLIER * 0.55)
           # 默认 VOLATILITY_MULTIPLIER = 1.85

14% 概率：trend = U(-0.5,0.5) * baseSigma * 0.95     # 硬切趋势
否则：    trend = 0.86*trend + N(0,1)*baseSigma*0.18

deviation = (basePrice - price) / basePrice
revertStrength = MEAN_REVERSION_BPS/10000 (=0.0045)；|dev|>60% 时 ×2.4
revert = deviation * revertStrength

effVol = baseSigma * (1 + min(2.5, volCluster) + max(0, newsBoost))
9% 概率 tailFactor ∈ [2.1, 2.8]，否则 1
shock = N(0,1) * effVol * tailFactor
move  = shock + trend + revert
next  = round(price * (1+move))，再 clamp 到 [base/4, base*4] ∩ [minPrice,maxPrice]
```

白话：每一小步都可能让价格自己跳好几个百分点；大约七分之一的步数会突然换方向；大约十一分之一的步数还会额外放大 2～3 倍。

### 1.3 数量级（为何「不真实」）

内置股 `volatility` 约 **0.032～0.085**（见 `StockMarket.java`）。

以中位股 `vol=0.05` 估算：

- `baseSigma ≈ 0.05 × 1.85 × 0.55 ≈ **0.0509**` → **单 tick 约 5% 标准差**
- 每小时约 720 tick：若独立相加，小时波动量级远超真实市场（真实个股常见小时波动约 0.3%～2%）
- 叠加 `volCluster`、`newsBoost`、9% 肥尾后，尖峰更夸张
- 新闻单次跳空最高 **22%**，并立刻把 `newsBoost`、`volCluster`、`trend` 打高，后续 tick 继续放大

文档 `2.0-审查与设计.md` 曾写「对数空间 + 伊藤项 + 单次 ±12%」，**当前 `MarketEngine` 并未实现对数/伊藤，也没有单 tick ±12% 硬夹**——这是方案必须补上的缺口。

### 1.4 成交冲击 / 做市 / 新闻

| 模块 | 现状 |
| --- | --- |
| `applyImpact` | `impact = min(0.045, qty/depth * 0.012)`，线性冲击，并改 `trend` |
| `MarketMakerEngine` | 五档按 `mid ± (i+1)*step`；`step ≈ mid * max(0.004, vol*0.14)`；量随 `trend` 偏斜；大单跨档只取两档均价 |
| `NewsEngine` | 游戏刻间隔 5～15 分钟；模板幅度常 5%～22%；直接改价 + 抬 `newsBoost/volCluster/trend` |
| 玩家成交 | `TradeService` 成交后一律调 `applyImpact` |

### 1.5 已有可复用状态

`Quote` 已持久化：`price, trend, volCluster, newsBoost, dayOpen/High/Low, volume, bars, 五档`。  
方案尽量 **改语义、少加字段**；必要新字段见 §5。

## 2. 设计目标与非目标

### 2.1 目标（服务器经济）

1. **降虚假尖峰与过山车**：默认配置下，安静时段价格以「细小来回」为主。  
2. **保留可玩性**：仍有趋势段、新闻事件、玩家大单推价；高波动股（VOID/SOUL/NETR）仍比蓝筹晃得大。  
3. **时间尺度正确**：波动按 **真实秒数 Δt** 缩放，改 `updateIntervalSeconds` 不会把波动「莫名放大/缩小到离谱」。  
4. **可落地**：只动 Java 服务端行情链路与配置；不依赖外部行情 API。  
5. **可验收**：给出可脚本化的统计指标（日波动、最大回撤、自相关等）。

### 2.2 非目标

- 不做真实券商对接、不做跨服同步。  
- 不做完整 Heston/Jump-Diffusion 蒙特卡洛引擎（CPU 要省，公式要能手写在一个方法里）。  
- 不改 Module-Shop 主仓经济 API。  
- 本轮 **只出方案**，不写代码、不开云端、不提 PR。

## 3. 推荐模型总览：「OU 对数公允价 + EWMA 波动率 + 护栏」

命名建议（实现时可叫 `PriceModelV3`）：**Log-OU + EWMA-σ + Session/Day Guard**。

### 3.1 核心直觉（给猫猫）

想象每只股票有一个「心里价」（公允价），现价围着它晃：

- 晃的大小 = 波动率（蓝筹小、妖股大）。  
- 波动率自己也会变：刚大涨大跌后会躁一会儿，再慢慢平静（像真实市场的「波动聚集」）。  
- 新闻不是把股价直接掰断，而是先推一把心里价，现价再慢慢跟上去。  
- 一天内涨跌有「安全带」，碰到了就减速，而不是直接钉死或继续疯跑。

### 3.2 状态变量（每只股票的 `Quote`）

| 符号 | 建议字段 | 含义 | 白话 |
| --- | --- | --- | --- |
| \(S\) | `price`（已有） | 成交/标价 | 玩家看到的现价 |
| \(F\) | **新增** `fairPrice`（long） | 公允中枢 | 股票「应该值多少」的慢变量 |
| \(\mu_t\) | `trend`（改语义） | 对数漂移（每秒） | 最近偏涨还是偏跌的劲头 |
| \(\sigma_t\) | **新增** `sigma`（或重用并改名 `volCluster`） | 瞬时波动率（每√秒） | 现在有多「晃」 |
| \(n_t\) | `newsBoost`（改语义为剩余冲击预算） | 新闻残余 | 新闻推完还剩多少劲 |
| — | `dayOpen/High/Low`（已有） | 日轨迹 | 用来算日振幅护栏 |

迁移：旧档无 `fairPrice` 时令 `fairPrice = price`；无 `sigma` 时令 `sigma = volHourly(def)`。

### 3.3 时间步

```
dtSec = UPDATE_INTERVAL_SECONDS   # 默认 5
dt    = dtSec / 1.0               # 秒
dtHour = dtSec / 3600.0
```

所有随机项按 \(\sqrt{dt}\) 或 \(dt\) 缩放，**禁止**再把「每小时波动」直接当成「每 tick 波动」。

### 3.4 把 `StockDef.volatility` 重新标定

**建议语义（破坏性但必要）：`volatility` = 目标小时对数波动率 σ_hour（无量纲）。**

| 档位 | 建议 σ_hour | 对应内置股例子 | 白话 |
| --- | --- | --- | --- |
| 低 | 0.008～0.015 | BRCK/RAIL/EMRD | 一小时大概晃 1% 上下 |
| 中 | 0.015～0.028 | FARM/COPP/GOLD | 有行情但不吓人 |
| 高 | 0.028～0.045 | VOID/SOUL/NETR | 刺激，但仍远低于现在每 5 秒 5% |

**迁移规则（实施时写进 Seeder/升级逻辑）：**

```
vol_new = clamp(vol_old * 0.35, 0.006, 0.050)
```

白话：旧数值大约打三五折再封顶，避免老存档继续「火箭」。管理员新建股时 UI 提示改为「小时波动（推荐 0.01～0.04）」。

全局倍率保留：

```
σ_base = def.volatility * VOLATILITY_MULTIPLIER
```

**新默认：`VOLATILITY_MULTIPLIER = 1.0`**（旧 1.85 废掉「再放大一截」的习惯）。

## 4. Tick 公式（可直接指导改 `evolveAndSample`）

以下均在 **开市且未停牌** 时执行。闭市/停牌：只 `sample` + 重建盘口（与现状一致）。

### 4.1 会话时段因子 \(s\)

即使 `SESSION_ALWAYS_OPEN=true`，仍建议用「软日历」调波动（可关）：

```
s = 1.0
若启用 SESSION_VOLUME_PROFILE：
  开盘后 15 分钟：s = 1.35
  收盘前 15 分钟：s = 1.25
  其余：s = 0.85～1.0（中段稍静）
  若始终开市：用「服务器本地钟」每小时的固定剖面，或用游戏日进度映射
```

白话：刚开盘和快收盘时热闹一点，中间稍微安静——像真股市。

配置项：`SESSION_PROFILE_ENABLED`（默认 true）、`SESSION_OPEN_BOOST`、`SESSION_MID_DAMP`。

### 4.2 更新瞬时波动率 σ（EWMA / 半 Heston）

目标水平：\(\bar\sigma = \sigma_{base} \cdot s\)

```
# 先用上一 tick 的已实现 |对数收益| 更新（首 tick 用 0）
r_prev = log(price / max(1, prevPrice))          # 上一成交价差
σ_target = σ_base * s
κ_σ = SIGMA_MEAN_REVERT          # 默认 0.08 / 秒？→ 用无量纲：每 tick 回归系数
# 实用离散：
sigma = sigma + KAPPA_SIGMA * (σ_target - sigma) * dtHour
      + XI_SIGMA * sigma * Z_σ * sqrt(dtHour)
sigma = clamp(sigma, σ_target * 0.45, σ_target * 2.2)

# 已实现冲击：大跳动后抬高一点
if abs(r_prev) > 1.6 * σ_target * sqrt(dtHour_prev):
    sigma = min(σ_target * 2.2, sigma + REALIZED_BUMP * abs(r_prev))
```

推荐默认：

| 参数 | 默认 | 白话 |
| --- | --- | --- |
| `KAPPA_SIGMA` | 2.5（每小时回归强度） | 躁动能在大约几十分钟内退烧 |
| `XI_SIGMA` | 0.35 | 波动率自己的噪声别太大 |
| `REALIZED_BUMP` | 0.15 | 刚出现大跳，短时更晃 |

**废弃** 旧的 `volCluster ∈ [0,2.5]` 线性乘数；其持久化字段可复用存 `sigma`，或新增 `sigma` 并在读档时兼容。

### 4.3 更新趋势 μ（OU，禁止硬切）

```
# 趋势单位：每小时对数漂移
mu = mu * exp(-KAPPA_TREND * dtHour) + SIGMA_TREND * Z_μ * sqrt(dtHour)
# 可选：极低概率进入「主题行情」——不是硬切，而是给 mu 一个温和目标
if U < THEME_PROB * dtHour:          # 例如每小时约 8% 概率触发主题
    mu += THEME_JUMP * (±1)          # THEME_JUMP 默认 0.01（约 1%/小时量级）
mu = clamp(mu, -MU_CAP, MU_CAP)      # MU_CAP 默认 0.04
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `KAPPA_TREND` | 1.2 / 小时 | 趋势半天内基本淡掉 |
| `SIGMA_TREND` | 0.02 | 趋势噪声 |
| `THEME_PROB` | 0.08 / 小时 | 偶尔走出一段方向 |
| `THEME_JUMP` | 0.012 | 主题强度 |
| `MU_CAP` | 0.045 | 防止单边起飞 |

**删除** 现状「14% 硬切 `trend = 随机`」。

白话：方向像天气——慢慢变，偶尔变天，不会每几秒掷骰子换南北风。

### 4.4 公允价 \(F\) 的慢漂移（锚定经济，避免全体阴跌）

```
# 对数空间 OU 拉向 basePrice，同时允许公允价极慢漂移（模拟「板块景气」）
f = fairPrice
logF = log(f)
logB = log(basePrice)
logF += KAPPA_FAIR * (logB - logF) * dtHour
      + mu * FAIR_FOLLOW * dtHour          # 趋势部分传导到公允价（默认 0.35）
      + news_fair_residual                   # 见新闻节
fairPrice = clampLong(round(exp(logF)), lowerSoft, upperSoft)
```

| 参数 | 默认 |
| --- | --- |
| `KAPPA_FAIR` | 0.15 / 小时（几天量级拉回基准） |
| `FAIR_FOLLOW` | 0.35 |

白话：股票有「老家」在基准价附近，但可以搬家；搬家很慢。

### 4.5 现价 \(S\)：对数 OU 跟公允价 + GBM 噪声 + 伊藤修正

```
logS = log(S)
gap = log(fairPrice) - logS
# 均值回归（把旧 MEAN_REVERSION_BPS 换成「每小时强度」）
κ_s = MEAN_REVERSION_PER_HOUR          # 默认 0.8
drift = κ_s * gap + mu * (1 - FAIR_FOLLOW) + 0.5 * sigma^2
# ↑ 最后一项是伊藤修正：防止「越晃越阴跌」
shock = sigma * Z_s * sqrt(dtHour)
# 肥尾：用「混合高斯」代替固定 9%×2.5——更稀、更可控
if U < JUMP_PROB * dtHour:             # 默认 JUMP_PROB=0.15/小时 ≈ 每天几次
    shock += JUMP_SCALE * sigma * Z_j  # JUMP_SCALE 默认 2.0
dlog = drift * dtHour + shock
# 单 tick 硬夹（防数值炸裂）
dlog = clamp(dlog, -TICK_MOVE_CAP, TICK_MOVE_CAP)   # 默认 0.025 = 单步最多约 ±2.5%
S_raw = exp(logS + dlog)
S_next = applyGuards(def, quote, S_raw)             # 日振幅 + 长期带
quote.moveTo(S_next)
```

| 参数 | 新默认 | 旧对应 | 白话 |
| --- | --- | --- | --- |
| `MEAN_REVERSION_PER_HOUR` | 0.8 | 旧 45bps/**每 tick** 过猛 | 偏了会慢慢拉，不是每 5 秒拽一把 |
| `TICK_MOVE_CAP` | 0.025 | （无） | 一步最多跳约 2.5% |
| `JUMP_PROB` | 0.15/小时 | 旧 9%/**每 tick** | 一天偶尔几次跳，不是十一分之一步一次 |
| `JUMP_SCALE` | 2.0 | 旧 2.1～2.8 | 跳的时候大约两倍平常晃度 |

**配置兼容：** 可保留 `MEAN_REVERSION_BPS` 作为「每小时万分比」的别名（例如 80 = 0.8/小时），避免运营文档两套词。

### 4.6 日振幅护栏与涨跌停（服务器经济安全带）

长期带保留：`[max(minPrice, base/4), min(maxPrice, base*4)]`。

**新增日振幅：**

```
dayRef = prevClose > 0 ? prevClose : dayOpen
upLimit   = dayRef * (1 + DAY_LIMIT_PCT)      # 默认 DAY_LIMIT_PCT = 0.12（±12%）
dnLimit   = dayRef * (1 - DAY_LIMIT_PCT)
# 软着陆：越靠近限额，有效 σ 与 drift 乘以 (1 - closeness)^2
closeness = max(0, (S - dayRef) / (dayRef * DAY_LIMIT_PCT) ) 的绝对值
若 closeness > 0.85：sigma_eff *= (1 - closeness)^2 + 0.05
最终 S = clamp(S, dnLimit, upLimit)
若触板：可设 quote.haltedSoft 本 session 剩余时间只允许反向或极小波动（可选，默认关）
```

| 模式 | 建议 |
| --- | --- |
| 默认 | **软日限 ±12%**（到了减速 + 硬夹） |
| 可选 | 硬涨跌停 ±10%，触板后本 tick 起至日切仅允许反向成交冲击松动（进阶） |
| 高波动股 | 允许 `StockDef` 覆盖 `dayLimitPct`（如 VOID=0.18） |

白话：一天之内先给安全带；快顶到了就减速，而不是突然锁死或继续飞。

### 4.7 模拟成交量与影线

```
# 基础量与 |dlog|、σ、会话因子相关
simVol = depth * DEPTH_VOL_FRAC * (0.4 + 0.6*U)
       * (1 + VOL_MOVE_GAIN * abs(dlog) / max(1e-6, sigma*sqrt(dtHour)))
       * s
wick = price * sigma * sqrt(dtHour) * (0.5 + abs(Z_w))
```

默认：`DEPTH_VOL_FRAC=0.008`，`VOL_MOVE_GAIN=0.8`。  
白话：晃得大、盘口深，成交量柱就高一点；别再用 `abs(move)*1800` 那种被旧大 move 喂胖的公式。

### 4.8 伪代码汇总（单票单 tick）

```
dtHour = updateIntervalSeconds / 3600
s = sessionFactor()
σ_target = def.volatility * volatilityMultiplier * s
updateSigma(quote, σ_target, dtHour)
updateMu(quote, dtHour)
updateFair(quote, def, dtHour)
dlog = ouGbmStep(quote, dtHour)           # 含伊藤、跳、tick cap
S = applyDayAndBandGuards(def, quote, exp(log(S)+dlog))
quote.moveTo(S)
sampleWickAndVolume(...)
MarketMakerEngine.rebuildOrderBook(...)
decayNewsBoost(quote, dtHour)
```

## 5. 新闻模型（改 `NewsEngine.applyNewsImpact`）

### 5.1 问题

现状：直接 `price *= 1+pct%`，pct 可达 22%，并 `newsBoost = absPct*2.4`、`volCluster += absPct*1.8`、重写 `trend` → 一次新闻等于「跳空 + 后续持续火箭」。

### 5.2 新机制：冲击拆成「公允跳」+「现价部分跟」+「短时波动抬升」

```
pct = clamp(rawPct, -AUTO_NEWS_MAX_IMPACT, +AUTO_NEWS_MAX_IMPACT)
# 新默认 AUTO_NEWS_MAX_IMPACT = 6（旧 22）
# 模板库的 min/max 建议整体 ×0.35 并封顶 8

fair' = fair * (1 + pct/100 * FAIR_NEWS_SHARE)     # FAIR_NEWS_SHARE=0.70
spot' = price * (1 + pct/100 * SPOT_NEWS_SHARE)    # SPOT_NEWS_SHARE=0.35
# 现价不必一次吃满；剩余靠 OU 去追 fair
sigma = min(σ_cap, sigma * (1 + abs(pct)/100 * NEWS_SIGMA_GAIN))  # NEWS_SIGMA_GAIN=1.2
mu   += sign(pct) * min(MU_CAP, abs(pct)/100 * NEWS_MU_GAIN)      # NEWS_MU_GAIN=0.25
newsBoost = abs(pct)/100 * 0.8                     # 仅作 UI/衰减标记，不再乘进 2.4× 巨型增益
```

模板幅度重标定建议（实施 checklist）：

- 正向模板：原 5～22 → **2～6**
- 负向模板：原 -19～-4 → **-6～-2**
- 宏观 `*`：同上

自动新闻频率：默认间隔可略拉长（如 8～20 分钟游戏刻），避免「新闻比行情还密」。

白话：新闻先改「大家觉得值多少」，现价只跟一部分；不会一条快讯直接腰斩或翻倍。

## 6. 成交量、冲击与做市耦合

### 6.1 玩家冲击（改 `MarketEngine.applyImpact`）

现状线性冲击易在中等深度上打出 4.5% 硬顶，且叠加自动行情变成双响炮。

推荐 **平方根冲击（Kyle / Almgren 简化）**：

```
adv = max(depth * ADV_FRAC, 1)              # ADV_FRAC 默认 0.05，近似「可吸收量」
x = quantity / adv
impact = IMPACT_COEF * sigma_hourly * sqrt(x)   # IMPACT_COEF 默认 0.15
impact = min(IMPACT_CAP, impact)                # IMPACT_CAP 默认 0.02（单笔最多约 2%）
# 永久 vs 临时：永久进 fair，临时进 price
fair *= (1 ± PERM_SHARE * impact)               # PERM_SHARE=0.35
price *= (1 ± impact)
mu += (±) * impact * IMPACT_MU                  # IMPACT_MU=0.10（旧 0.25 减半）
rebuildOrderBook
```

方向：买单 `+`，卖单 `-`。

白话：单子越大越推价，但推法是「越来越费劲」的曲线，不是直线捅穿；大单会留一点长期痕迹在公允价上。

### 6.2 做市盘口（改 `MarketMakerEngine`）

```
# 价差与瞬时 σ、会话因子挂钩
halfSpread = max(1, round(mid * max(MIN_SPREAD, SPREAD_COEF * sigma * sqrt(dtHour))))
step = halfSpread
# 库存偏斜：用 mu 与 (price-fair)/fair
skew = clamp(SKU_COEF * mu + GAP_COEF * (price-fair)/fair, -0.25, 0.25)
mmBidVol *= (1 + skew)
mmAskVol *= (1 - skew)
```

大单执行价：由「两档平均」升级为 **按档累计量加权均价**（仍可不做完整连续簿）：

```
remaining = qty
cost = 0
for level in asks(or bids):
  take = min(remaining, level.vol)
  cost += take * level.price
  remaining -= take
  if remaining==0: break
if remaining>0: cost += remaining * lastPrice * (1 ± SLIP_EXT)
return cost / qty
```

白话：盘口厚度和价差跟着「现在有多晃」走；砸大单会一层层吃，价格更像样。

### 6.3 与 `TradeService` 的耦合顺序（保持）

建议维持：

1. 自动行情演化 / 新闻  
2. 重建盘口  
3. `matchAll`（限价触及）  
4. 成交 → `applyImpact` → 再 `rebuildOrderBook`  
5. 强平 / 过期 / 指数  

注意：冲击改 fair+spot 后，**同一 tick 内** 避免新闻与冲击互相用旧 `volCluster` 乘数放大；冲击函数只读 `sigma`。

## 9. 验收指标（可脚本 / 可单测）

在 **无玩家成交、新闻可关** 的条件下，对每只代表股跑 **N=200 条路径 × 真实 2 小时**（`dt=5s` → 1440 tick）：

| 指标 | 低波股（如 BRCK）目标 | 中波（FARM） | 高波（VOID） | 旧模型问题对照 |
| --- | --- | --- | --- | --- |
| 单 tick \|收益\| 中位数 | < 0.15% | < 0.25% | < 0.40% | 旧常 >1%～3% |
| 单 tick \|收益\| 99 分位 | < 1.0% | < 1.5% | < 2.5% | 旧常 >5%+肥尾 |
| 2 小时收益标准差 | 1%～3% | 2%～5% | 4%～9% | 旧动辄 20%～50%+ |
| 2 小时最大回撤中位数 | < 4% | < 7% | < 12% | 旧常腰斩级 |
| 日振幅触达 ±12% 的路径占比 | < 5% | < 10% | < 20% | 旧无日限 |
| 收益一阶自相关（lag1） | 0.05～0.25 | 同左 | 同左 | 硬切导致乱跳、可预测性差 |
| \|r\| 的自相关（波动聚集） | 显著为正 | 同左 | 同左 | 需要有「闹一阵」 |
| 路径中位期末价 / 起点 | 0.97～1.03 | 同左 | 0.95～1.05 | 旧无伊藤时易阴跌 |

**有新闻（默认频率）再跑一批：**

- 单次新闻引起的 **现价** 瞬时跳动中位 \|Δ\| ≤ 3%，95 分位 ≤ 6%  
- 新闻后 30 分钟内额外年化不多于「σ 抬升 ≤ 1.8× 并消退」

**有玩家冲击：**

- `qty = 0.02 * depth`：冲击约 0.3%～0.8%  
- `qty = 0.20 * depth`：冲击约 1%～2%，且 ≤ `impactCap`

**体感验收（给猫猫）：**

1. 挂机 30 分钟看 K 线：应像「有起伏的折线」，不是心电图。  
2. 出一条新闻：有跳、有讨论，但不至于全服破产/暴富。  
3. 用一大笔市价单：有滑点、盘口变稀，但下一分钟不应继续单边闪崩。  
4. 开关 `priceModelVersion` 能立刻感到旧模型更吵。

建议补纯 Java 单测：`PriceModelV3Test`（固定 RNG 种子断言上述分位数落窗）。

## 12. 给实施者的最小接口契约

```text
MarketEngine.evolveAndSample(...):
  输入：def, quote, dt(由 config 推), RNG
  输出：更新 quote.price/fairPrice/sigma/trend/newsBoost/day* ；写 bar；rebuild book

MarketEngine.applyImpact(..., qty, buySide):
  更新 fair+price+trend(+sigma 微抬)；rebuild book；幅度 ≤ impactCap

NewsEngine.applyNewsImpact(..., percent,...):
  拆分 fair/spot；抬 sigma/mu；广播文案不变

Config:
  priceModelVersion=3 时走新路径，=2 时旧路径
```

随机数：继续 `Random` 即可；单测注入种子。无需外部 RNG / Python。

## 13. 总结（可转述给猫猫）

现在的股市像「每几秒掷一次超级骰子」，所以会假、会晕、会炸经济。  
新方案让股票：**大多时候慢慢晃、有时走出一段方向、新闻推一把但不砸断、大单会留下脚印、一天有安全带**。  
这些都能写进现有的 `MarketEngine` / 新闻 / 做市里，用配置调「闷」还是「刺激」，并用一串统计数字验收——不用接真实股市，也不用先大重构客户端。
